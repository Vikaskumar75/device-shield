---
title: Screenshot protection
description: Block screenshots and screen recording of sensitive screens on Android.
---

import { Aside } from '@astrojs/starlight/components';

```dart
await DeviceShield.initialize();

final applied = await DeviceShield.enableScreenshotProtection();
// … show the sensitive screen …
await DeviceShield.disableScreenshotProtection();
```

To protect the whole app from launch, set
`DeviceShieldConfig(enableScreenshotProtection: true)` instead.

## Android

The SDK sets `WindowManager.LayoutParams.FLAG_SECURE` on your activity's
window. The operating system then:

- blocks screenshots (the user sees a "can't take screenshot" message),
- shows black in screen recordings and casts, and
- hides the app's thumbnail in Recents.

`enableScreenshotProtection()` returns `false` only when no activity is
attached, for example during a background start.

<Aside type="caution" title="Shared with app-switcher protection">
  Screenshot protection and [app-switcher protection](../app-switcher/) use the
  same `FLAG_SECURE` flag on Android. Disabling either one clears the flag for
  both, even though the other's `is…Enabled` getter still reports `true`.
  Enable and disable them together on Android.
</Aside>

`FLAG_SECURE` stays set after `DeviceShield.shutdown()`. Call
`disableScreenshotProtection()` before shutting down if you want it cleared.

## iOS

<Aside type="danger" title="Does not work on iOS">
  iOS has no supported API for blocking screenshots. The SDK's current
  technique relies on undocumented UIKit internals. In Simulator testing,
  screenshots were **not** blocked and the app's layout broke. The call can
  still return `true`. Don't use it on iOS.
</Aside>

On iOS, use [screenshot detection](../../detection/screenshot/) to react
after the fact, and [app-switcher protection](../app-switcher/) to hide
content in the app switcher.
