Signals appear in `result.signals`, each with a strength that decides how
much it counts. See [Detection results](../../concepts/detection-results/)
for the rule. The strengths live in
[`signal_strengths.dart`](https://github.com/Vikaskumar75/device-shield/blob/main/app/lib/src/signal_strengths.dart),
and a test fails if native code emits a signal missing from it.

## Choosing strengths

A strength reflects how often a signal fires on devices that aren't
compromised. They're our assessment, based on how each check works. Measure
them against your own users before blocking anyone.
