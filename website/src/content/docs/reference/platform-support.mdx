## Feature support

| Feature | Android | iOS |
|---|---|---|
| Root detection | ✓ | Not applicable |
| Jailbreak detection | Not applicable | ✓ (not applicable on the Simulator) |
| Emulator / simulator detection | ✓ | ✓ |
| Debugger detection | ✓ | ✓ |
| Mock location detection | ✓ (location signals need permission) | Limited |
| Screenshot detection | API 34+ | ✓ |
| Screen recording detection | — | ✓ |
| Screenshot protection | ✓ (`FLAG_SECURE`) | Experimental |
| App-switcher protection | ✓ (shares `FLAG_SECURE`) | ✓ |

## Verification status

What has actually been observed running, as of 0.1.0:

| Feature | Android 17 emulator (API 37) | iOS 26.5 Simulator |
|---|---|---|
| Every check runs without failing | ✓ | ✓ |
| Emulator / simulator detection | ✓ `hardware`, `product` | ✓ `simulator_target` |
| Root / jailbreak on a clean device | ✓ clear | ✓ not applicable (Simulator) |
| Debug build not reported as debugger | ✓ | ✓ |
| Screenshot detection | ✓ | Not tested |
| Screenshot protection | ✓ black system screenshot and `screencap`, also after rotation | Installs cleanly; **blocking not verifiable on the Simulator** |
| App-switcher protection | ✓ (same flag) | ✓ |
| No crash on attach (Android 14+ permission) | ✓ | — |

**Not yet verified anywhere:** physical Android devices, physical iPhones, a
rooted or jailbroken device, a device using a fake-GPS app, and iOS versions
before 26.5.
